# Document Standards

## 共通
- 日本語ドキュメントのデフォルトフォント: 游ゴシック（本文）、游明朝（見出し可）
- 英語ドキュメントのデフォルトフォント: Calibri
- 日付形式: YYYY年MM月DD日 または YYYY/MM/DD
- ファイル名に日付を含める場合: YYYYMMDD プレフィックス

## Word (.docx)
- ヘッダー/フッターにタイトルとページ番号を入れる
- 見出しスタイル（Heading 1〜3）を使用して目次生成可能にする
- A4 縦が基本、横が必要な場合は明示

## Excel (.xlsx)
- 1行目はヘッダー行（太字、背景色付き）
- 印刷範囲とヘッダー行の固定を設定
- 数値にはカンマ区切り書式を適用
- シート名は日本語で分かりやすく

## PowerPoint (.pptx)
- 16:9 ワイドスクリーン
- タイトルスライド + 目次 + 本文 + まとめ の構成が基本
- 1スライド1メッセージ
- フォントサイズ: タイトル28pt以上、本文18pt以上

## PDF
- 既存PDFの編集時はフォント埋め込みに注意
- 日本語テキスト抽出時は文字化けを確認
