# Schedule Manager

ブラウザで動くガントチャート管理ツール。React + Vite + TypeScript で構築。

## 機能

- ガントチャート表示（日 / 月 / 四半期 / 年のズーム切替）
- ドラッグ＆ドロップによるバー編集（移動・リサイズ）
- スイムレーン管理（追加・並び替え・タグ付け）
- マイルストーン表示
- 接続線（依存関係）の作成 — スナップポイント付き接続モード対応
- PNG / PDF エクスポート
- JSON インポート / エクスポート
- localStorage によるデータ自動保存
- ライト / ダークテーマ切替
- 固定幅 / 自動フィットの表示モード（フォントサイズ自動調整）
- 複数ページ管理

## 使い方マニュアル

### 基本操作

| 操作 | 方法 |
|---|---|
| バーの追加 | ツールバー「+ ▼」→「Bar」、または「配置 ▼」→「Bar」でチャートクリック |
| マイルストーンの追加 | ツールバー「+ ▼」→「Milestone」、または配置モードで同様 |
| レーンの追加 | ツールバー「+ ▼」→「Lane」 |
| 編集 | ダブルクリックで編集ダイアログ |
| 移動・リサイズ | ドラッグ＆ドロップ |
| 削除 | 選択後 Delete キー、または右クリック→Delete |
| 複数選択 | Ctrl + クリック |

### ツールバーボタン一覧

```
💾  保存            ↩ ↪  Undo/Redo
+ ▼ 追加メニュー    🔗  接続モード
配置 ▼ 配置モード    Tip / Memo  表示トグル
Day/Month/Q/Year    Fixed/Fit  表示モード
📍  今日へスクロール  ⚙  フォント設定
?  使い方マニュアル  🌙/☀️  テーマ切替
⋯ ▼ ファイル操作     Saved  保存状態
```

### 接続（依存関係）の作成

**接続モード（推奨）:**
1. ツールバーの 🔗 をクリック（カーソルが十字に変化）
2. 始点のアイテムにホバー → 辺上にスナップポイント（●）が表示
3. 始点のスナップポイントをクリック → 始点確定
4. 終点のアイテムのスナップポイントをクリック → 接続作成
5. ESC または背景クリックでキャンセル

**従来の方法:**
2つのアイテムを Ctrl+クリックで選択 → 右クリックメニュー →「接続を作成」

### ズームと表示モード

- **Day / Month / Q / Year**: 時間軸の粒度を切替
- **Fixed**: 固定列幅で表示
- **Fit**: ブラウザ幅に合わせて自動フィット（文字サイズも自動調整）

### エクスポート・インポート

ツールバーの「⋯ ▼」メニューから：
- **Import**: JSON ファイルの読み込み
- **Download**: JSON 形式でデータ保存
- **PNG**: 画像エクスポート
- **PDF**: PDF エクスポート

### アプリ内マニュアル

ツールバーの **?** ボタンをクリックすると、アプリ内でマニュアルを参照できます。

## データの安全性・機密性について

### 完全ローカル動作

このアプリは **すべてのデータをブラウザの localStorage に保存** します。外部サーバーへのデータ送信は **一切行いません**。

### サーバーレスアーキテクチャ

- 静的ファイル（HTML / CSS / JavaScript）のみで構成
- バックエンドサーバー・データベース **不使用**
- API 通信 **なし**
- Cookie / トラッキング **なし**

### オフライン対応

初回読み込み後はインターネット接続なしで完全に動作します。

### 機密情報の保護

- 入力されたプロジェクト名、タスク名、メモ等の情報は **すべてお使いのブラウザ内にのみ保存** されます
- 第三者がネットワーク経由でデータにアクセスすることは **不可能** です
- ソースコードは公開されており、データ送信がないことを検証可能です

### バックアップの推奨

ブラウザのキャッシュクリアや localStorage 削除でデータが失われる可能性があります。
定期的に「⋯ ▼」→「Download」でバックアップを保存してください。

## 技術スタック

- **フロントエンド:** React 19 + TypeScript
- **ビルド:** Vite 6
- **状態管理:** Zustand
- **エクスポート:** html2canvas + jsPDF

## はじめかた

```bash
cd webapp
npm install
npm run dev
```

`http://localhost:5173` で起動します。

Windows の場合はルートの `start.bat` をダブルクリックでも起動できます。

## ビルド

```bash
cd webapp
npm run build
```

`webapp/dist/` に出力されます。

## デプロイ (Vercel)

Vercel の静的 SPA デプロイに対応しています。

- **Framework Preset:** Vite
- **Root Directory:** `webapp`
- **Build Command:** `npm run build`
- **Output Directory:** `dist`

クライアントサイドルーティング用のリライトは `webapp/vercel.json` で設定済みです。
